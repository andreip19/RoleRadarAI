# RoleRadar AI

Intelligent Job Discovery and Career Matching Platform.

## Overview

RoleRadar AI is a platform designed to discover job opportunities,
extract technical skills and match job requirements with candidate profiles.

## Technologies

- Python 3.13
- FastAPI
- SQLAlchemy
- PostgreSQL
- Web Scraping
- Playwright
- Large Language Models
- LangChain
- pgvector
- React
- Docker
- GitHub Actions

## Current Status

Initial backend development.

## Planned Features

- Automated job discovery
- Public job board integrations
- Job data normalization
- AI-powered skill extraction
- Semantic job search
- Candidate-job matching
- Career analytics dashboard
